================================================================================
                         KEY DECISION POINTS
================================================================================

┌─────────────────────────────────────────────────────────────────────────┐
│ DECISION: Should PM be notified?                                       │
│                                                                         │
│ Input: Knowledge gap analysis result                                   │
│                                                                         │
│ IF criticality IN ['high', 'critical']                                 │
│    → NOTIFY                                                             │
│                                                                         │
│ OR IF urgency_score >= 7                                               │
│    → NOTIFY                                                             │
│                                                                         │
│ OR IF recommended_action IN ['notify_pm', 'escalate_urgent']          │
│    → NOTIFY                                                             │
│                                                                         │
│ ELSE                                                                    │
│    → DON'T NOTIFY (just show AI suggestion to sales rep)               │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ CRITICALITY ASSESSMENT (by GPT-4o)                                     │
│                                                                         │
│ Analyzes:                                                               │
│ 1. Question about our product? (vs general chat)                       │
│ 2. Does sales rep have this info? (knowledge base check)               │
│ 3. Buying intent signals?                                               │
│    - "evaluating between you and X"                                     │
│    - "we need this for..."                                              │
│    - "can you support..."                                               │
│    - "during contracting/pricing discussion"                            │
│ 4. Is this time-sensitive?                                              │
│    - Deal in progress                                                   │
│    - Technical evaluation                                               │
│    - Competitor comparison                                              │
│                                                                         │
│ Output:                                                                 │
│ - criticality: none/low/moderate/high/critical                         │
│ - urgency_score: 0-10                                                   │
│ - has_buying_intent: true/false                                         │
│ - why_critical: explanation                                             │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
